# Sport Predictor — локальное веб-приложение

Приватный MVP с интерфейсом в браузере. Можно открыть на компьютере или телефоне в той же сети, а позже развернуть в интернете. По умолчанию приложение запускается только на твоём компьютере.

## Запуск

Нужен Python 3.10+.

### Windows
```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

### macOS / Linux
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Открой URL, который покажет Streamlit (обычно `http://localhost:8501`).

## Функции MVP
- интерфейс с пятью видами спорта;
- загрузка доступных событий ESPN для отдельных футбольных соревнований, NBA и ATP;
- ручной ввод матча и коэффициентов;
- базовая оценка вероятности, объяснение и предупреждение о нехватке данных;
- SQLite-история прогнозов и виртуальный P/L;
- проверка доступности источников.

## Ограничения
Последние пять матчей, травмы, составы, детальная статистика и коэффициенты автоматически пока не подключены. OpenDota проверяется, но надёжное будущее расписание в этой версии не выводится. CS2 расписание не подключено. Модель при ручных коэффициентах опирается на рынок и не является доказанным независимым прогнозом.

BetBoom не подключён: используем только официальный разрешённый способ, если доступность и условия подтвердятся. Не передавай пароли, cookies и коды подтверждения. Приложение не размещает реальные ставки.

## Приватность и бесплатный запуск
Локальный запуск бесплатен и не требует Telegram-бота. База хранится в `predictions.sqlite3` рядом с кодом. Не запускай с `--server.address 0.0.0.0`, если не понимаешь сетевые последствия. Чтобы делиться с кем-то через интернет, потребуется отдельное развёртывание и защита доступа; бесплатные облачные тарифы могут засыпать или менять условия.
